# Atas de Reunião com Assinaturas Múltiplas

Página única (`atas/index.html`), sem dependências nem servidor. Abra no navegador.

1. Identificação, participantes, pauta, encaminhamentos e encerramento.
2. Cada signatário presente assina com o dedo ou o mouse no próprio aparelho.
3. A assinatura fica vinculada ao SHA-256 do texto. Se o texto mudar, ela é invalidada.
4. "Gerar PDF / Imprimir" monta a ata em A4 (linhas em branco para quem não assinou).

Rascunho salvo automaticamente no navegador; "Salvar arquivo" exporta JSON para reabrir depois.

**Valor jurídico:** é assinatura eletrônica simples (Lei 14.063/2020, art. 4º, I). Serve para atas internas e reuniões de equipe.
Quando a ata vai a registro (junta comercial, cartório) ou o estatuto exige outra forma, use assinatura avançada/qualificada (gov.br, ICP-Brasil) ou assinatura física.
